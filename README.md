# central-admin

แอปแอดมินกลาง — จัดการข้อมูล **About / Donate** ของทุกแอปในเครือ (parauy และแอปอื่นๆ ในอนาคต)
จากที่เดียว แยกข้อมูลกันอิสระด้วย **App ID** — แอปหนึ่งใช้ PromptPay, อีกแอปใช้บัญชีธนาคารคนละธนาคารก็ได้ ไม่ปนกัน

## ตั้งค่าก่อนใช้งาน

1. รันไฟล์ `supabase-setup-multiapp.sql` (ส่งมาพร้อมกัน) ใน Supabase Dashboard → SQL Editor → New query → Run
   (ถ้าเคยรัน `supabase-setup.sql` เวอร์ชันเก่ามาก่อน ไฟล์นี้จะย้ายข้อมูลเดิมมาเป็น app_id = "parauy" ให้อัตโนมัติ)
2. คัดลอก `.env.example` เป็น `.env.local` แล้วใส่ `VITE_SUPABASE_URL` และ `VITE_SUPABASE_ANON_KEY`
   (**ใช้ Supabase project เดียวกับทุกแอปในเครือ** — นี่คือ "ที่เก็บกลาง")

## รันดู / Deploy

```bash
npm install
npm run dev      # ทดสอบในเครื่อง
npm run build    # ได้โฟลเดอร์ dist/ พร้อม deploy
```

Deploy เป็นอีกโปรเจกต์บน Vercel แยกจากทุกแอป — ตั้งค่า Environment Variables บน Vercel ให้ตรงกับ `.env.local` ด้วย

## วิธีใช้

1. เปิดแอป → กรอกรหัสผ่านผู้ดูแล (546287) ที่ช่องบนสุด — ใช้ได้กับทุกแอปในรายการ ไม่ต้องกรอกซ้ำทุกครั้งที่สลับแอป
2. หน้าแรกจะเห็นรายชื่อแอปทั้งหมดที่เคยตั้งค่าไว้ กดที่แอปไหนก็แก้ไขได้เลย
3. กด **"+ เพิ่มแอปใหม่"** เพื่อสร้างแอปใหม่ในระบบ — ตั้ง App ID ให้ไม่ซ้ำกับที่มีอยู่ (เช่น `parauy`, `app2`, `app3`)
4. แต่ละแอปกรอกช่องทางรับเงินได้อิสระ — จะใช้ PromptPay, บัญชีธนาคาร, หรือลิงก์ ก็เลือกกรอกเฉพาะที่ใช้จริง เว้นว่างช่องที่ไม่เกี่ยวได้เลย
5. หน้าแอปแต่ละตัว (เช่นแอปพารวย) ต้องตั้งค่า `APP_ID` ในซอร์สโค้ดของตัวเองให้ตรงกับ App ID ที่ตั้งไว้ที่นี่ ถึงจะดึงข้อมูลถูกแถว

## ความปลอดภัย

- รหัสผ่าน (546287) เช็คฝั่ง Supabase function เท่านั้น ไม่ได้เช็คในโค้ดฝั่งนี้ — ปลอดภัยแม้มีคนเปิดดูโค้ดของแอปนี้
- หน้านี้ไม่ได้ทำ index ให้ search engine แต่ยังเป็น URL สาธารณะ — ไม่ควรแชร์ลิงก์ให้ใครนอกจากตัวเอง
- อยากได้ความปลอดภัยเพิ่ม ตั้งค่า Vercel Password Protection (ฟีเจอร์ Vercel Pro) ครอบอีกชั้นได้
